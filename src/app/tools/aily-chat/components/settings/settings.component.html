其他设置
用户级 Instruction Folders
每行一个绝对路径，lex 会递归扫描其中的 *.instructions.md。
项目级 Instruction Folders
每行一个绝对路径，优先级低于用户级，高于仓库自动发现。
Terminal 自动放行规则
每行一个规则。支持命令前缀，或 /^...$/i 形式的正则字面量。
Terminal 强制确认规则
命中这些规则时，即使是默认安全命令也会进入审批。
关闭后，只有上面的自动放行规则会跳过审批。
AI编辑完成后自动保留变更，不弹出变更面板
最大请求数（工具调用轮数）
对齐 VS Code 的 chat.agent.maxRequests（默认 200）：限制一次请求中代理最多还能继续发起多少轮工具调用与模型请求。
